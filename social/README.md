# Мониторинг соцсетей · городской округ Мытищи

Система собирает посты и комментарии из сообществ Telegram и ВКонтакте, отбирает сообщения про городской округ Мытищи и его администрацию, размечает тему, тональность и адрес и показывает всё на карте и в отчётах.

Адрес: **https://social.a-platonov.ru** (сервер Webdock в Дании).

## Что умеет

- **Сбор.** 37 источников из списка заказчика (`app/sources.py`), новые добавляются на странице «Источники». Сообщества и страницы администрации проверяются каждые 10 минут, соцсети губернатора — каждые 5. Комментарии под постами собираются 3 дня после публикации, у губернатора — 7 дней.
- **Соцсети губернатора.** Под постами А. Воробьёва (t.me/vorobiev_live, vk.com/andreyvorobiev) сохраняются только комментарии про округ. Признаки — город Мытищи с микрорайонами и все 92 населённых пункта округа (`app/localities.py`). Такие комментарии получают высший приоритет отработки. Свои слова для отбора можно добавить в «Настройках».
- **Разметка.** Claude определяет, касается ли сообщение округа, и проставляет тональность, тему, упоминание администрации, адрес, населённый пункт и проблему. Темы: ЖКХ, благоустройство, здравоохранение, образование, дороги и транспорт, прочее. Комментарий относится к той же проблеме, что и его пост. Без ключа Claude работает разметка по словарям (`app/topics.py`), она грубее.
- **Карта.** Адреса переводятся в координаты через OpenStreetMap (Nominatim) только в границах округа. Сообщение, где назван только населённый пункт, ставится в его центр. Сообщения без адреса, где упомянут только город Мытищи, на карту не попадают: точка в центре города ничего бы не сказала. Цвет идёт от жёлтого (мало сообщений) к красному (много), цветов ниже жёлтого нет. Период: час, 3 часа, сутки, неделя, месяц, квартал, год или свой. Можно фильтровать по темам, тональности, соцсети и типу источника.
- **Отработка.** Очередь сообщений по приоритету: губернатор, затем негатив на страницах администрации и обсуждаемые сообщения. Статусы: «Новое → В работе → Отработано / Не требует». Проблему можно переименовать, объединить с другой и дописать заметку.
- **Отчёты**, все в PDF и с отправкой в MAX:
  1. **Сутки 8:00–8:00.** Список проблем по приоритету: упоминания (вес 2), комментарии (вес 1), сообщения у губернатора (вес 3). Блок губернатора идёт первым.
  2. **По проблеме.** Что, где и как написано: все сообщения со ссылками и тональность комментаторов.
  3. **По темам за сутки или неделю** со сравнением с прошлым периодом.

  Отчёт можно сохранить как шаблон и отправлять в MAX каждый день в заданное время: текст с разметкой и PDF-файл.

## Установка на сервер

Сервер `platonov` (45.136.71.18, Ubuntu 24.04).

1. **DNS.** В Cloudflare для `a-platonov.ru` добавьте A-запись `social` → `45.136.71.18`, Proxy status: **DNS only**. Тогда Caddy сам получит сертификат.
2. **Установка.** По SSH под root:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/sasha-russia/development/main/social/install.sh | BRANCH=main bash
   ```

   Пока изменения не влиты в `main`, укажите ветку: `BRANCH=claude/funny-davinci-nhvskh` (и тот же путь вместо `main` в адресе скрипта).

   Скрипт ставит Docker, скачивает код в `/opt/social-monitor` и создаёт `.env` с паролем администратора (он покажет его один раз). Затем запускает приложение и Caddy с HTTPS. Если порты 80/443 уже заняты (например, VPN), Caddy не запускается: приложение будет слушать `127.0.0.1:8000`, а проксирование нужно настроить в уже работающем веб-сервере.
3. **Ключи** в `/opt/social-monitor/social/.env`, после правки снова запустите скрипт:
   - `TG_API_ID`, `TG_API_HASH` — https://my.telegram.org → API development tools. Затем «Настройки → Telegram»: телефон, код, облачный пароль. Лучше завести отдельный аккаунт: каналы и чаты читаются от его имени.
   - `VK_TOKEN` — сервисный ключ любого своего приложения VK (vk.com/apps?act=manage → «Настройки»).
   - `ANTHROPIC_API_KEY` — ключ Claude API (console.anthropic.com). Модель по умолчанию `claude-opus-5-5`. Для большого потока можно поставить `CLAUDE_MODEL=claude-haiku-5-5`: она в десятки раз дешевле, но точность разметки надо проверить на своих сообщениях.
   - `MAX_BOT_TOKEN` и `MAX_CHAT_ID` (или `MAX_USER_ID`) — бот на платформе MAX для партнёров, добавленный в чат или канал, куда идут отчёты.
4. **Закрытые чаты.** Ссылки `t.me/joinchat/…` и `t.me/c/…` читаются, только если аккаунт в них состоит. Для приглашений на странице «Источники» есть кнопка «Вступить». В закрытые группы `t.me/c/…` аккаунт нужно добавить вручную.

Обновление — тот же скрипт. База лежит в `/opt/social-monitor/social/data/social.db` (SQLite), её и `.env` нужно включить в резервное копирование.

## Разработка

```bash
cd social
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
ADMIN_PASSWORD=demo DISABLE_SCHEDULER=1 python -m app.demo   # тестовые сообщения, только локально
ADMIN_PASSWORD=demo DISABLE_SCHEDULER=1 uvicorn app.main:app --reload
python -m pytest
```

Устройство: FastAPI и SQLite в одном процессе. Планировщик (`app/worker.py`) каждую минуту проверяет, каким источникам пора на сбор, затем размечает новые сообщения и рассылает отчёты по расписанию. Сборщики: `app/collectors/telegram.py` (Telethon, аккаунт пользователя) и `app/collectors/vk.py` (`wall.get` / `wall.getComments`). Разметка — `app/classify.py`, геокодер — `app/geocode.py`, отчёты — `app/reports.py` (данные) и `app/templates/_report_body.html` (вид на экране и в PDF, WeasyPrint), MAX — `app/max_bot.py`.

## Ограничения

- Telegram ограничивает частоту запросов. При `FloodWait` источник пропускает круг, причина видна на странице «Источники».
- Публичный Nominatim принимает 1 запрос в секунду. Результаты кешируются, но при большом потоке новых адресов карта заполняется с задержкой.
- В базе хранятся имена авторов и тексты сообщений из открытых сообществ. Доступ к системе — только по логину. Порядок хранения таких данных стоит согласовать с юристом (152-ФЗ).
